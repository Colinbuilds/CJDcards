Label studio

Printing tips: in the print dialog, set Scale to 100% (or "Actual size"), Margins to None, and turn off headers and footers. For a thermal printer, pick the matching label size as the paper size. Print one sheet on plain paper with "Print outlines" on to check alignment, then use "Fine-tune alignment" if it's off.
